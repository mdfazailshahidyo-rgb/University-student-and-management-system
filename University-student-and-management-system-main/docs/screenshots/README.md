### Capture steps

1. Start XAMPP/WAMP and open `index.php`, **or** run `node demo/server.js` and
   open `http://localhost:3000`.
2. Sign in with `admin` / `admin123`.
3. Use your OS screenshot shortcut (Windows `Win + Shift + S`, macOS
   `Cmd + Shift + 4`, Linux `Print Screen`) or Chrome DevTools →
   *Capture screenshot*.
4. Add the images to the report under section **7. Output screenshots**.

> Screenshot images are intentionally not committed: they must show a live run
> of the finished application on the demonstration machine.
